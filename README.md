# Project Template

This is a project template for software design and development exercises.

## Getting Started

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd specification-exercice
   ```

2. **Read the specifications**
   - `specs/requirements.md` - What the project should do
   - `specs/design.md` - How to build it
   - `specs/tasks.md` - Step-by-step implementation tasks

3. **Start implementing**
   Follow the tasks in order and update the changelog as you work.

## Project Structure

```
├── specs/                  # Project specifications
│   ├── requirements.md     # Feature requirements
│   ├── design.md          # Technical design
│   ├── tasks.md           # Implementation tasks
│   └── changelogs.md      # Development log
└── README.md              # This file
```

## Workflow

1. Read all specification files
2. Follow tasks sequentially
3. Update changelog after completing work
4. Mark tasks as complete when done

## Need Help?

- Check the specification files for guidance
- Follow the tasks step by step
- Document your progress in the changelog

Good luck! 🚀
